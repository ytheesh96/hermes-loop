# Resource Library Format

```markdown
# Resources: [Topic]

## [Resource title]
- **Type:** official docs | primary source | textbook | paper | worked example
- **URL / citation:** [stable source]
- **Accessed:** YYYY-MM-DD
- **Authority:** [why this source is credible]
- **Scope:** [what it covers and omits]
- **Difficulty:** introductory | intermediate | advanced
- **Use in mission:** [outcome or lesson supported]
- **Notes/conflicts:** [uncertainty or disagreement]
```

Verify links and claims before recording them. Generated explanations are not resources unless clearly marked as agent-authored synthesis with source citations.
