# Learning Glossary Format

```markdown
# Glossary: [Topic]

## [Term]
- **Meaning:** [learner-facing definition]
- **Not this:** [nearby misconception]
- **Example:** [concrete use]
- **Related:** [links to terms or lessons]
- **Evidence/source:** [citation]
- **Learner status:** introduced | recognized | used with support | demonstrated
```

Keep mastery status evidence-based. A term is not demonstrated merely because it was explained.
